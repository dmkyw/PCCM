# 咸阳市第一人民医院呼吸科微信H5宣传页面

## 项目功能描述

本项目是为咸阳市第一人民医院呼吸与危重症医学科开发的微信H5宣传页面，旨在为患者提供专业的呼吸科疾病科普教育和医院服务介绍。

### 主要功能特性

#### 🏥 医院品牌展示
- 展示医院官方徽标和科室信息
- 体现医院专业形象和品牌价值
- 突出呼吸与危重症医学科的专业性

#### 📚 疾病科普教育
- **真实案例分享**：通过张阿姨的故事引起患者共鸣
- **常见误区纠正**：纠正"咳嗽=感冒"等错误认知
- **疾病类型介绍**：科普慢性支气管炎、哮喘、慢阻肺等常见疾病
- **居家护理指导**：提供实用的日常护理建议

#### 🩺 专业医疗建议
- 强调网络信息的局限性
- 引导患者到正规医院就诊
- 提供专业的医生温馨提醒

#### 📱 移动端优化
- 响应式设计，完美适配各种屏幕尺寸
- 微信环境优化，提供流畅的浏览体验
- 支持一键拨号功能
- 优化的加载速度和交互体验

#### 📞 便民服务
- 提供科室咨询电话（029-33248083, 029-33281175）
- 显示医院详细地址信息
- 链接到医院官方网站

## 项目技术架构

### 技术栈
- **HTML5**：语义化页面结构
- **CSS3**：现代化样式设计，支持响应式布局
- **JavaScript**：交互功能和微信环境优化
- **SVG**：矢量图形，确保在各种设备上的清晰显示

### 文件结构
```
Wechat/
├── index.html              # 主页面文件
├── style.css               # 样式文件
├── script.js               # 交互脚本
├── hospital-logo.svg       # 医院徽标（SVG格式）
├── 项目规格文件.md          # 项目规格文档
└── README.md               # 项目说明文档
```

### 设计特色
- **色彩方案**：以医院绿色（#2E8B57）为主色调，体现医疗专业性
- **布局设计**：垂直滚动单页面，模块化内容组织
- **交互体验**：平滑的滚动动画和点击反馈
- **微信适配**：针对微信内置浏览器进行专门优化

## 项目部署方式

### 方式一：本地开发环境部署

#### 环境要求
- Python 3.x（用于启动本地服务器）
- 现代浏览器（Chrome、Firefox、Safari、Edge等）
- 微信开发者工具（可选，用于微信环境测试）

#### 部署步骤
1. 确保所有项目文件在同一目录下
2. 打开命令行工具（PowerShell、CMD等）
3. 导航到项目目录
4. 启动Python HTTP服务器
5. 在浏览器中访问页面

### 方式二：Web服务器部署

#### 支持的服务器
- Apache HTTP Server
- Nginx
- IIS（Windows）
- 任何支持静态文件的Web服务器

#### 部署要求
- 支持HTTPS协议（微信要求）
- 支持MIME类型配置
- 建议配置Gzip压缩以提高加载速度

### 方式三：CDN部署

#### 推荐的CDN服务
- 阿里云CDN
- 腾讯云CDN
- 百度云CDN
- GitHub Pages（适合演示）

## 项目执行步骤

### 步骤1：环境准备
```powershell
# 检查Python版本
python --version

# 如果没有Python，请从官网下载安装
# https://www.python.org/downloads/
```

### 步骤2：下载项目文件
```powershell
# 创建项目目录
mkdir D:\kktrae\Wechat
cd D:\kktrae\Wechat

# 将所有项目文件放置在此目录下
```

### 步骤3：启动本地服务器
```powershell
# 在项目目录下执行
python -m http.server 8080

# 服务器启动成功后会显示：
# Serving HTTP on :: port 8080 (http://[::]:8080/) ...
```

### 步骤4：访问页面
```
# 在浏览器中打开以下地址
http://localhost:8080

# 或者
http://127.0.0.1:8080
```

### 步骤5：移动端测试

#### 方法一：浏览器开发者工具
1. 在Chrome浏览器中按F12打开开发者工具
2. 点击设备模拟器图标（手机图标）
3. 选择不同的设备型号进行测试

#### 方法二：微信开发者工具
1. 下载并安装微信开发者工具
2. 创建新项目，选择"小程序"类型
3. 在项目中打开H5页面进行测试

#### 方法三：真机测试
1. 确保手机和电脑在同一网络
2. 获取电脑的IP地址
3. 在手机浏览器中访问：http://[电脑IP]:8080

### 步骤6：微信环境测试

#### 测试要点
- [ ] 页面在微信中正常显示
- [ ] 电话号码可以正常拨打
- [ ] 外部链接可以正常跳转
- [ ] 页面滚动流畅
- [ ] 字体大小适中，易于阅读
- [ ] 图片和徽标清晰显示
